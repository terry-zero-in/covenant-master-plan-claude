# 04 — ENGINE / AGENT / HUMAN / GATE / QUIET-LOG MAP

The five-lane law (`08-ENGINE-AGENT-HUMAN-GATE-QUIET-LOG-LAW.md`) applied to every workflow chapter. Per-surface briefs carry their own five-lane tables; this is the whole-product reconciliation — the single place to check that no responsibility is double-assigned and no shipping number is ever computed outside the ENGINE lane.

Trust hierarchy (LOCKED): **"The Analyst prepares. Covenant calculates. The borrower reviews, certifies, and sends."**

## 2. Lane invariants (checked in every brief)

1. **No shipping number outside ENGINE.** The agent may quote engine output (with provenance); it may never produce a figure that lands in a package. Narrative drafts that contain figures interpolate engine values by reference, not by generation — a draft's numbers re-render from the engine at view time, so an edited draft can never carry a stale or hallucinated figure into a package. (This is the mechanism behind "never mutates a ground-truth number past a human gate.")
2. **Gates are decisions, not events.** Every gate in the table names its typed decision options in the owning brief, per the gate law (exact ask, why blocked, evidence, affected fields, recommendation, consequence of delay, audit record).
3. **Quiet log is append-only and identity-stamped** (actor, evidence, loan/period/package, outcome, next scheduled action). Completed autonomous work never pushes; the only push-eligible class is deadline escalation per org policy.
4. **Agent presence is contextual, not chrome.** The agent shows up as: proposed extraction beside its source page; classification confidence beside an arrival; the remembered answer beside the field; headroom beside the test; the drafted narrative beside the shortfall; the gate beside the blocked step. There is no generic chat box added to any surface to "demonstrate AI" — the Ask surface (highlight-anything-to-ask + the ask panel) is the one deliberate conversational entry point, and it is grounded or it refuses (its brief specifies grounding and refusal).
5. **Fail-closed renders honestly.** A blocked computation renders as a blocked state naming what is missing — never a plausible placeholder. Fixture-era habits (demo strings standing in for computed values) are the anti-pattern this invariant retires.
